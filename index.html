Vérificateur Open Badges 3.0

Collez ou déposez un badge numérique : l'outil affiche son contenu en clair (émetteur, bénéficiaire, dates, critères) et signale les champs manquants ou mal formés. Gratuit, sans inscription. Le badge reste dans votre navigateur, rien n'est envoyé sur un serveur.

Vous pouvez aussi déposer un fichier ici : .json, .jwt, ou une image de badge .png / .svg contenant ses données.

Ce que l'outil contrôle

Le vérificateur compare le badge aux exigences de la spécification Open Badges 3.0 publiée par 1EdTech :

  • les contextes JSON-LD (@context) et les types attendus (VerifiableCredential, OpenBadgeCredential) ;
  • l'identifiant du badge et l'émetteur (issuer) ;
  • les dates de début et de fin de validité, et si le badge est expiré ;
  • le bénéficiaire (credentialSubject) et la manière dont il est identifié ;
  • la réalisation certifiée (achievement) : nom, description, critères ;
  • la présence d'une signature (proof ou format JWT).

Limites. L'outil contrôle la structure du badge. Il ne vérifie pas la signature cryptographique et n'interroge pas le service de révocation de l'émetteur : un badge « conforme » ici est bien formé, ce qui ne prouve pas à lui seul son authenticité.

Questions fréquentes

Qu'est-ce qu'un Open Badge 3.0 ?

Un Open Badge est une attestation numérique de compétence, de formation ou de réalisation. La version 3.0 s'appuie sur le modèle Verifiable Credentials du W3C : le badge est un document JSON signé par son émetteur, que chacun peut conserver, partager et faire vérifier.

Où trouver le JSON de mon badge ?

La plateforme qui a émis le badge propose en général un téléchargement au format JSON ou une image PNG ou SVG dans laquelle les données sont intégrées. Les deux peuvent être déposés ici.

Mon badge est en version 2.0, est-il accepté ?

Non. Les badges Open Badges 2.0 ont une structure différente ; l'outil les reconnaît et vous l'indique, sans les contrôler.

Comment savoir si un badge m'appartient ?

Quand le bénéficiaire est identifié par une adresse e-mail, souvent enregistrée sous forme d'empreinte, saisissez votre adresse dans le champ proposé sous le résultat : l'outil vous dit si elle correspond.
